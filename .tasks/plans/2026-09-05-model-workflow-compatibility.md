## 구현 결정 및 중간 검증

- 사용자 지정 전역 설정 경로는 완전 지원 대신 변경 전 오류로 중단한다. 프로젝트 범위는 계속 지원한다. 기존 매니페스트의 소유권 범위를 확장하지 않았다.
- 스킬 권한 회귀 1개와 POSIX 진입점의 사용자 지정 경로 반례 4개에서 RED를 확인하고 GREEN으로 전환했다.
- 독립 스킬 검토의 승인 의미·배치 참조·직접 실패 처리 지적 3개를 수정했고, 재검토에서 모두 해결 및 GO를 받았다.
- Windows PowerShell 5.1 설치·제거 통합 테스트가 통과했다. 새 경로 검사, 54개 inline-hook fixture, 실제 훅 프로세스 실행을 포함한다.
- 첫 Python 검사는 npm 네트워크 제한과 Windows 임시 폴더 권한 제한에 걸렸다. npm 오프라인 설정과 승인된 Windows 임시 폴더 접근으로 재검증했다.
